So funktioniert die Aktualisierung

Diese Seite lädt die öffentliche Datei data.json beim Öffnen und alle 60 Sekunden. Sie zeigt neue Werte erst, nachdem der private Paper-Bot sie übertragen und GitHub Pages sie veröffentlicht hat.

Neue Werte können verzögert erscheinen. Eine fehlende Übertragung wird als veralteter Snapshot gekennzeichnet.
Nur virtuelle Ergebnisse. Keine echte Börsenverbindung, keine Echtgeld-Orders, keine Anlageberatung und keine garantierte Rendite.
